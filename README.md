# Wildfire Cellular Automata Spread Canvas
Simulate wildfire spread on an 80×60 grid using probabilistic cellular automata with wind, humidity, and terrain controls.
## Features
- 80×60 cell grid with Empty, Tree, Burning, and Burned states
- Wind direction compass (8 directions) and wind speed amplify spread probability downwind
- Humidity slider reduces spread probability; tree density sets initial forest coverage
- Fire tool: click to ignite cells; Firebreak tool: click-drag to clear trees and create barriers
- Real-time stats showing cells burning, burned, and percentage of forest remaining
## Usage
Click "Apply & Reset" after changing density to regenerate the forest. Click on a tree cell with the Fire tool active to start a fire, then press Play to run the simulation. Use the Firebreak tool to drag-clear tree corridors before igniting.
